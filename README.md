# Horizen5.github.io

Horizen5 的个人主页，部署在 GitHub Pages 上。

## 网站地址

https://horizen5.github.io

## 技术栈

- **HTML5** - 页面结构
- **CSS3** - 样式与响应式布局
- **JavaScript** - 交互逻辑（平滑滚动、动画效果、移动端菜单）

## 项目结构

```
.
├── index.html          # 主页面入口
├── 404.html            # 404 错误页面
├── .nojekyll           # 禁用 Jekyll 引擎
├── README.md           # 项目说明
├── assets/
│   ├── css/
│   │   └── style.css   # 主样式表
│   └── js/
│       └── main.js     # 主脚本文件
```

## 页面模块

| 模块 | 描述 |
|------|------|
| Header (导航栏) | Logo、项目名、菜单链接 |
| Hero Section | 核心标语、快速开始按钮 |
| Feature Cards | 核心功能展示 |
| Skills | 技术栈与技能进度条 |
| Footer | 版权声明、社交媒体链接 |

## 特性

- 响应式设计，支持移动端
- 平滑滚动导航
- 技能条进入视口时的动画效果
- 渐变色主题
- 卡片悬停效果
- 移动端菜单
